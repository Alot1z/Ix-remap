Ix maps a repository into a graph of its symbols, calls and imports, stored on your machine. You query the
graph from the `ix` CLI, from AI agents over MCP, and in the Compass visualizer. These docs cover installing
Ix, using it day to day, connecting your agents, and the full reference for every command, flag and endpoint.

## Install

```bash
curl -fsSL https://ix-infra.com/install.sh | sh    # macOS / Linux
```

On Windows, or to see what the installer sets up, read [Installation](/getting-started/installation/).
