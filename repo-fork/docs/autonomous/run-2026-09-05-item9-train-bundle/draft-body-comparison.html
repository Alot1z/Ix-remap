What this ships

The one-time setup notice (ix first run in a workspace) prints the Ix logo as a terminal banner instead of the plain text heading.

  • scripts/render-logo.mjs renders assets/logo.png at print time. Zero dependencies: PNG chunk decode → inflate → unfilter → coverage-thresholded supersampling → flat 5-tone snap → half-block output. The PNG is the only maintained art; the terminal render is derived from it on every run.
  • Truecolor with ANSI-256 and ASCII fallbacks. --color auto honors NO_COLOR, TERM=dumb, FORCE_COLOR; the no-color path emits zero escape bytes.
  • --bg none paints only the logo's own pixels (unbacked ▀/▄ half-blocks), so the mark reads cleanly on light terminal themes. --bg brand (default) keeps the current backdrop. --json reports bg honestly.
  • Absent-safe: a layout without the renderer or the asset falls back to the plain text heading — the banner is decoration, never load-bearing. stderr-only, so --format json|llm output stays clean.
  • Golden fixtures in output-samples/ (truecolor/256/ascii × brand/none) with output-stability pins.
  • assets/logo.png already exists on main — no binary asset is added, only the renderer, wiring, tests, and goldens.
  • Rebased onto main at the last branch update (39d0734); main's workspace-canonicalization change in bootstrap.ts is preserved (verified on a fresh clone of main). Upstream main has since advanced to e8ab1926 (the #547/#559 exit-code wave merged, 2026-09-05); a final rebase onto that head runs before this PR is marked ready.

Tests

  • Focused suite: 21 pins in bootstrap-notice.test.ts — stderr-not-stdout, absent-safe renderer/asset, NO_COLOR zero-escapes, exit-code contracts, --bg none invariants (backdrop constant never appears as a background; library ≡ CLI byte-for-byte; JSON honesty), and byte-identity against the goldens.
  • Mutation-checked locally: breaking the no-color contract turns the NO_COLOR pin red; disabling the --bg none emission path turns its pin red. Both restored green.
  • Full ix-cli suite on the merged head (Windows): 95 files, 1704 passed / 21 skipped; tsc --noEmit clean.
